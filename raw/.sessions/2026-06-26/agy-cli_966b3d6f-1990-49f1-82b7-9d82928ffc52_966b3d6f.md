입력 후 아무런 텍스트가 올라오지 않는다면 **AI 서버와 통신을 실패하고 무한 대기 중인 상태**입니다.
가장 유력한 원인은 터미널에 'API 키'가 세팅되어 있지 않기 때문입니다! (Open Interpreter는 기본적으로 유료인 ChatGPT-4o 모델을 찾으려고 시도합니다.)

당황하지 마시고 이렇게 대처해 보세요.

### 🛠️ 해결 방법

**1. 일단 강제 종료하기**
반응이 없는 터미널 창에서 키보드의 `Ctrl + C`를 두세 번 연속으로 눌러서 `root@DESKTOP-QBALFK6:~#` 프롬프트(명령어 입력창)로 빠져나옵니다.

**2. API 키 세팅 후 다시 실행하기**
아까 저희가 겪었던 문제와 똑같이, Open Interpreter도 외부 AI 두뇌를 빌려 쓰려면 API 키가 필요합니다. 
구글 AI 스튜디오에서 발급받으신 Gemini API 키가 있다면, 터미널에 아래와 같이 **모델을 명시해서** 다시 켜주세요.

```bash
# 환경변수에 키 등록 (본인 키로 변경 필요)
export GEMINI_API_KEY="여기에_발급받은_키_입력"

# Gemini 모델을 사용하겠다고 명시하며 실행
interpreter --model gemini/gemini-1.5-pro
```

*(만약 ChatGPT Plus 결제를 하셔서 OpenAI API 키가 있으시다면 `export OPENAI_API_KEY="..."`를 하시고 그냥 `interpreter`만 치시면 가장 성능이 좋습니다!)*
