1. 프로젝트 개요

프로젝트는 크게 세 계층으로 구성됩니다. 프론트엔드(src/)는 React + TypeScript 기반으로 계약서 작성 폼, 미리보기, PDF 출력을 담당합니다. 백엔드(server/src/)는 Express + TypeScript로 인증, 계좌, 거래내역, 이체 API를 제공합니다. 데이터 계층(supabase/)은 Edge Functions와 마이그레이션으로 구성됩니다.

5. 리팩터링 권장사항

분석 결과를 바탕으로 우선순위가 높은 리팩터링 대상을 선정했습니다.

Priority 1 — createContract (CCN 49)
극도로 높은 분기 복잡도. 계약 생성 로직을 Validation → Build → Save 3단계로 분해하고 각 단계를 별도 모듈로 추출하십시오.
Priority 2 — validateStep (CCN 44)
4개 Step의 검증이 하나의 함수에 집중. Step별 검증 함수를 개별 파일로 분리하고 공통 검증은 유틸리티로 추출하십시오.
Priority 3 — useContractForm (258 라인)
Hook이 지나치게 비대합니다. useFormNavigation, useFormValidation, useFormSubmission 등 하위 hook으로 분리하십시오.
Priority 4 — validateLaborContract (CCN 25, 174 라인)
검증 규칙이 하나의 함수에 밀집. 필수 필드, 급여, 근로시간, 보험 등 도메인별 검증기를 개별 파일로 분리하십시오.
Priority 5 — auth route (CCN 30, 119 라인)
라우터 핸들러가 인증, 토큰 검증, 세션 관리까지 과도한 책임. 미들웨어 체인으로 분리하십시오.
